### 2.4 字段结构（待确认，需下载 xlsx 实际查看）

| 字段 | 是否包含 | 置信度 |
|---|---|---|
| 学校代号 | 是 | 高 |

| 专业组代号（或专业代号） | **待确认** | 中 |

| 计划数 | 可能无（通常在"招生计划"表里） | 中 |
| 投档人数 | 可能有 | 中 |

### 2.5 关键不确定点：院校最低分 vs 专业最低分

河北自 2024 年起本科批实施 **"专业（类）+ 学校"** 模式（类似山东）：

- 如果严格按该模式投档，每个专业一条独立投档线 → **专业最低分 + 专业位次**（理想情况，可直接复用山东数据模型）
- 若考试院仍按传统口径发布"院校专业组"汇总 → 只能拿到专业组级别最低分

**重要**：搜索结果里出现"招生院校数 2167（历史）/ 2367（物理）"而非"专业数"，暗示考试院层面可能**按"院校+专业组"统计**，但实际投档单位是专业。**必须下载真实 xlsx 核实，这是最大风险点**。

## 4. 招生计划

### 4.1 发布形式

- **主发布源**：纸质《招生计划》书（考试院编印，考生人手一本），电子版通过考试院官网 PDF 发布
- **电子版规律**：未在官网直接找到 2025 年本科招生计划 PDF 直链（搜索结果里只有高职单招 PDF）
- **推测路径**：招生计划 PDF 文件可能嵌入在"志愿填报智能参考系统"（gk.hebeea.edu.cn）内部，仅登录考生可见。**官网公开发布 PDF 的可能性不高**

### 4.2 已确认的细分计划

- **高职单招招生计划**（PDF，公开）：http://file.hebeea.edu.cn/files/article/2025/03/20250328175650_442.pdf
- **高职单招招生简章**（PDF，公开）：http://file.hebeea.edu.cn/files/article/2025/04/20250407175844_696.pdf
- 普通专升本招生计划（PDF，公开）：见 imgbdb4.bendibao.com 转载
- **普通本科招生计划**：未找到公开直链，可能仅印刷发行 + 系统内查询

### 4.3 替代获取路径

- 各高校本科招生网（如 zhaoban.hbu.cn、zs.hebut.edu.cn）发布的"分省分专业招生计划"PDF

- **风险**：分散、覆盖不全、非一手数据

## 5. 志愿填报模式

| 维度 | 河北 | 对比山东 |
|---|---|---|
| 选科模式 | **3+1+2**（物理/历史 二选一 + 再选二科） | 3+3（山东） |
| 批次结构 | 本科批（本科提前批 A/B、普通本科批、对口本科）+ 专科批 | 常规批 + 提前批 |
| 志愿模式 | **专业（类）+ 学校** | 专业（类）+ 学校 |
| 志愿数量 | 普通类 **96 个**，艺术/体育 70 个 | 96 个 |
| 录取方式 | 平行志愿 + 征集志愿（本科批 1 次集中 + 2 次征集） | 平行志愿 + 征集志愿 |
| 投档单位 | 按"专业+学校"逐条投档 | 按"专业+学校"逐条投档 |

**好消息**：河北的志愿模式**几乎与山东一致**（都是专业+学校、96 志愿、平行志愿），**数据模型可直接复用山东的 schema**。只需多加一个"首选科目（物理/历史）"维度。

## 6. 抓取难度评估

### 难度：**中等偏低**

### 理由

**有利因素：**
- 考试院所有核心数据（投档、一分一段）都**公开发布**，无需登录
- URL 命名规律清晰（`/html/xxgl/tzgg/YYYY/…` + `file.hebeea.edu.cn/files/article/YYYY/MM/`）
- 投档数据为 xlsx 原生表格，**易解析**（比 PDF 好太多）
- 历年数据覆盖完整：2021-2025 五年全齐
- 志愿模式与山东完全对齐，**可复用山东代码架构**
- 数据量可估：~2200-2400 所招生院校，每所 1-N 个专业组，总数据量大概率在 **山东量级的 60-80%**

**不利因素：**
- **file.hebeea.edu.cn 和 www.hebeea.edu.cn 连接不稳**（本次侦查多次 socket 关闭）→ 需重试 + 代理
- **一分一段表是 PDF**（非 xlsx），需 pdfplumber 或类似工具解析，成本略高
- **招生计划书无公开 PDF**（2025 本科），需要从各高校官网聚合或从志愿参考系统反爬
- 投档表字段"专业"还是"专业组"**需实际下载确认**
- 2021-2023 的历史数据是否仍采用"专业+学校"模式需要核实（2024 开始改革）

### 预估工时

| 任务 | 工时 |
|---|---|
| 下载 2025 本科批 xlsx 并分析字段结构 | 0.5 天 |
| 编写 xlsx 解析器（复用山东代码框架） | 1 天 |
| 抓取 2021-2025 五年本科批 + 提前批 + 专科批 | 1 天 |
| 一分一段表 PDF 解析 | 1 天 |
| 招生计划数据聚合（难点） | 2-3 天 |
| 入库 + 清洗 + 联调 | 2 天 |
| **合计** | **约 1.5-2 周** |

对比山东入库工时的 **60-70%**（因架构可复用）。

## 7. 推荐抓取路径

### 第一步：下载样本并确认字段（**最优先**）

直接下载两份 2025 xlsx，确认**"院校专业组最低分"还是"专业最低分"**：
- 历史组：http://file.hebeea.edu.cn/files/article/2025/07/20250722214851_332.xlsx
- 物理组：http://file.hebeea.edu.cn/files/article/2025/07/20250722214852_210.xlsx

下载 2021 组对照看字段演变（新高考首年）。

### 第二步：枚举历年公告页

按年月遍历 `/html/xxgl/tzgg/YYYY/MM-DD-HHMMSS-XXX.html` 不现实，更好方式：
1. 爬栏目列表页（http://www.hebeea.edu.cn/html/xxgl/tzgg/ 分页）
2. 或用 eol.cn 河北站作为索引（连接稳定）
3. 按标题关键字过滤"投档情况统计"

### 第三步：抓 xlsx → 入库

- 按 `年份 × 批次 × 首选科目` 三维度组织
- 字段映射到现有山东 schema，新增 `subject_type`（物理/历史）列

### 第四步：一分一段 PDF 解析

- 用 pdfplumber 抓取表格结构
- 分段映射到 `score → count → cumulative_count` 三字段

### 第五步：招生计划兜底策略

- 先抓各高校本科招生网（覆盖 211/985 + 河北省属大学）
- 再抓主流聚合站（gaokao.eol.cn、gk100.com）
- 最后人工补齐缺口

## 8. 不确定的问题（需要用户确认）

1. **字段层级**：投档数据是"专业最低分"还是"专业组最低分"？→ 需下载一份 xlsx 确认（建议授权立刻下载样本）
2. **招生计划范围**：Me Offer 是否必须包含招生计划数（每个专业招多少人）？若必须，需要额外 2-3 天做聚合
3. **历年回溯深度**：抓 2021-2025 五年，还是只抓 2023-2025 三年（新高考稳定后）？2021 是河北新高考首年，字段结构可能与后续不完全一致
4. **是否包含专科批**：工作量增加约 30%，数据价值视 Me Offer 目标用户定位而定
5. **是否包含对口/艺术/体育批次**：小众但数据更复杂（艺术类多个子类），预算外
6. **数据更新策略**：2026 年新数据是"自动监听公告 + 增量入库"还是"每年 7 月集中手工更新"？

---

## 一句话总结

**难度：中等偏低 | 数据完整度：~90%（核心投档+一分一段齐全，招生计划略缺）| 强烈建议开工**，优先先下载一份 2025 xlsx 核实字段结构，1 小时内即可决定技术路线。
